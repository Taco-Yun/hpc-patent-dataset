# Step 6 test outputs

Figures and reference files of two local test runs of the step 6 pipeline notebook
(`colab/step6_patentsum_pipeline.ipynb`). They show what the notebook writes; the dataset itself is distributed
separately from this repository.

| Folder | Run |
|---|---|
| `figures_full/` | Full profile: the complete input (21,947 records), with the generated layers (facets, summaries, embeddings, clusters) reused from the released run. Local computer (Apple M4, PyTorch on MPS); section 8.14 (BERTScore) left out. 38 min, no errors; all 17 key numbers equal those of the released run (`reference/run_report_key_numbers.csv`). |
| `figures_sample/` | Sample profile: 400 input records drawn at random, with the facets and summaries generated by the small stand-in model Qwen2.5-0.5B-Instruct (no CUDA GPU was available). The run checks that every step works; figures that depend on the generated text are not comparable with the release. 1 h 54 min, no errors. Run on 2026-10-12 with the same figure code. |
| `reference/` | Files of the full run: `run_report_key_numbers.csv` (this run next to the released run), `MANIFEST_release.csv` (files of `release/`), `NAME_MAPPING_ipc_to_cpc.csv` (release names, section 9.4), and the output of `colab/reproduce_figures_tables.ipynb` on this run (`Fig1_construction.png`, `Fig2_two_views.png`, Tables 1, 2, 3 and 5, `numbers_in_the_text.csv`). |

at most 6.6e-7); the other four embedding sets are identical to the release.

## 中文說明

本資料夾是第六步 pipeline notebook（`colab/step6_patentsum_pipeline_tw.ipynb`）兩次本機測試執行的圖與參考檔，
用來呈現 notebook 會產生什麼；資料集本身另行發布，不在本 repository。

| 資料夾 | 執行 |
|---|---|
| `figures_full/` | 完整版：完整輸入（21,947 筆），生成結果（分面、摘要、向量、分群）沿用釋出版本。本機（Apple M4，PyTorch MPS）執行，略過第 8.14 節（BERTScore）。38 分鐘，沒有錯誤；17 個關鍵數字與釋出版本全部相同（`reference/run_report_key_numbers.csv`）。 |
| `figures_sample/` | 抽樣版：隨機抽 400 筆輸入，分面與摘要由小型替代模型 Qwen2.5-0.5B-Instruct 生成（本機沒有 CUDA GPU）。這次執行只確認每一步都能跑；依生成文字而來的圖不能與釋出版本比較。1 小時 54 分，沒有錯誤；2026-10-12 執行，畫圖程式與現在相同。 |
| `reference/` | 完整版執行的檔案：`run_report_key_numbers.csv`（本次與釋出版本並列）、`MANIFEST_release.csv`（`release/` 的檔案清單）、`NAME_MAPPING_ipc_to_cpc.csv`（釋出名稱，第 9.4 節），以及 `colab/reproduce_figures_tables_tw.ipynb` 在本次執行上的輸出（圖 1、圖 2、表 1、2、3、5、`numbers_in_the_text.csv`）。 |

各圖的檔名、所屬章節與內容見上方英文表格（兩個資料夾的檔名相同；PNG 為 300 dpi，HTML 為可互動的 plotly 圖）。

`reference/Table5_classification_probe.csv` 有一個值與釋出版本不同：synthesized 向量的三碼正確率在此為 67.3%，
釋出版本為 67.4%（1,325 筆測試資料中差 1 筆）。這次本機測試的 synthesized 向量是由釋出的單位長度向量重建的
（差異最多 6.6e-7），其餘四組向量與釋出版本完全相同。
